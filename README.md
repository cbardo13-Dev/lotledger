# LotLedger

Inventory and profit tracking for bulk resellers (TikTok Shop, Whatnot, lives).
Static web app hosted on GitHub Pages; data in Supabase (Row Level Security per shop).

- `index.html` — the app
- `config.js` — Supabase project URL + publishable key (public by design; never put a secret key here)
- `sw.js`, `manifest.webmanifest`, icons — install-to-home-screen support
